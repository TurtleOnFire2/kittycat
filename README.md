mraow~

## Commands

- `/kc` — opens gui
- `/kc hud` — opens hud editor
- `/kc macros` — opens chat macro menu

## Features

### Misc
- **Bestiary HUD** — Displays info like bestiary gained per hour and an ETA until the next level
- **Chat Macros** — Runs something on configurable messages
- **Pests** — Auto set spawn, auto warp, ESP

### Dungeons
- **Auto LB** — Releases and repulls LB after configurable tick amount
- **Storm** — Auto swap crit item, auto swap armor, auto release LB, auto track storm, auto walk forward, auto swap to term, auto left click with term (you should use a term autoclicker with this, as it only sets the keystate to down…)

### Visual
- **Custom ESP** — `/cesp`
- **Arrow Tracers** — Tracers for your arrows…

### Kuudra

- **Rend Macro** :
-   Auto sneak: Sneaks when getting tped down
-   Auto jump: Jumps at edge
-   Auto Hollow Wand: Uses hollow wand when tping down (order in setting below)
-   Auto rod: Uses rod after tping down or using hollow wand depending on if you have the setting enabled/if you have a hollow wand in your hotbar
-   Auto throw bone: Automatically throws the bone when you exit a rectangle which you can config (the 3d render is a bit broken)
-     Bone delay: The fastest it will throw the bone after rod
-   Auto Halberd: After using the bone (be it manually or with the auto throw) it swaps to halberd and right clicks it
-   Auto loadout: After using halberd (be it manually or with the auto halberd) it opens the loadout menu and clicks the selected slot. Automatically closes the gui afterwards
-   Auto pull: After using ice spray it will swap to the selected slot and left click.
